# Blue Moth für Android (APK über GitHub bauen)
1. Neues privates GitHub-Repository anlegen und ALLE Dateien dieses Ordners hochladen (auch `.github` und `www`).
2. Reiter **Actions → Build Blue Moth (Android APK) → Run workflow**.
3. Nach ca. 5–10 Minuten unter **Artifacts → Blue-Moth-Android** die `app-debug.apk` herunterladen, aufs Handy kopieren und installieren (Installation aus fremden Quellen kurz erlauben).
Standard-Login: `mothy` / `blue777`. Creator-Zugang: Datei `creator.key` auf dem Handy auswählen (nicht ins Repository hochladen).
Nicht enthalten: Google-Anmeldung, Windows-Programme/EXE.
